# 🎄 Magic Christmas Tree (v2.0)

A magical, interactive web application to generate unique Christmas Trees based on your keywords!

![Preview](./preview.png)

## ✨ Features
- **Magic Generation**: Type words like "Rabbit", "Pizza", or "Love" to create unique themed trees.
- **Bilingual Support**: Fully localized for **English** and **Chinese**.
- **Massive Database**: Supports 200+ specific keywords including Chinese Zodiacs, Asian Food, and Internet Slang.
- **Holiday Card Export**: Save a beautiful, clean `.jpg` snapshot of your creation to share with friends.
- **Audio & Atmosphere**: Jingle Bells background music and dynamic snow effects.

## 🚀 How to Run
1.  Install dependencies:
    ```bash
    npm install
    ```
2.  Start local server:
    ```bash
    npm run dev
    ```

## 📸 How to Share
1.  Build for production:
    ```bash
    npm run build
    ```
2.  Deploy to GitHub Pages:
    ```bash
    npm run deploy
    ```

## 🛠️ Technologies
- React + Vite
- TailwindCSS
- PostCSS
- html2canvas (for export)
- Lucide React (Icons)
